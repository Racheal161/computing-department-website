# Department of Computing Website

A simple three-page website created for the assignment **Managing a Web Development Project Using Git and GitHub**.

## Files
- `index.html` — homepage
- `about.html` — department introduction and sample programmes
- `contact.html` — sample contact information and demo enquiry form
- `style.css` — shared responsive styling

## Run locally
Open `index.html` in a web browser. The contact form is a front-end demonstration only and does not send messages.
